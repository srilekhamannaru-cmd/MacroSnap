# 🥗 MacroSnap

MacroSnap is an AI-powered nutrition chatbot that uses Google Gemini to analyze food from text descriptions or photos and estimate calories and macronutrients.

## Features

- 🥗 Food identification
- 📸 Food photo analysis
- 💬 AI nutrition chat
- 🔥 Calorie estimation
- 💪 Protein, carbohydrates and fat estimation
- 📧 Send the conversation summary to email

## Technologies Used

- Python
- Streamlit
- Google Gemini
- Gmail SMTP
